What is this?

Watch real pilots fly around you.

This free addon pulls live ElevateX network flights and injects them into MSFS 2024 as AI aircraft. Each one gets a proper FSLTL model and airline livery, moving smoothly in real time based on actual pilot positions.

Requirements

What you need.

  • Microsoft Flight Simulator 2024
  • FSLTL Traffic Base installed in your Community folder
Install

Up and running in a minute.

  1. Download the zip above
  2. Extract it anywhere
  3. Start MSFS 2024 and load your flight
  4. Run ElevateXTrafficInjector.exe as admin
  5. Enter your ElevateX username (optional — excludes your own flights)
  6. Press START
How it works

Built on the live feed.

Every 12 seconds the injector downloads the ElevateX live feed, picks the flights nearest to you, matches each to an FSLTL model and livery, and spawns them via SimConnect. Between feed updates it interpolates smooth motion so aircraft glide continuously instead of teleporting.

Known bugs

What we're fixing.

Takeoff surge — aircraft on the runway can suddenly accelerate then settle repeatedly instead of rolling smoothly.
Pitch attitude — nose-up/down during climbs and descents is not always correct yet.
